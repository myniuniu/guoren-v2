# 通答平台「在线学习服务师数字专家培训系统」PRD

## 1. 文档说明

### 1.1 文档目的

本文档用于描述基于通答平台建设“在线学习服务师数字专家培训系统”的产品需求，作为产品设计、交互设计、研发拆解、测试验收和项目实施的依据。

本系统以通答平台现有能力为底座，围绕“AI 专家全程伴学、考证通关、职业成长”建设完整培训闭环。

### 1.2 产品定位

“在线学习服务师数字专家培训系统”面向在线学习服务师职业技能培训场景，服务考证人群、在岗提升人群和转行入门人群。系统通过智能体、知识图谱、能力模型、题库测评、情景模拟、学习任务、督学管理、证书档案等能力，为学员提供个性化、可追踪、可达标的学习成长服务。

### 1.3 核心目标

1. 帮助学员明确学习目标、当前能力水平、能力差距和报考建议。
2. 根据学员画像和前测结果生成个性化学习计划。
3. 以知识图谱连接国标能力点、课程、题库、情景任务、专家数字人和结业要求。
4. 通过智能体调度问卷、任务、日历、空间、研习社学习广场、资料库、知识图谱、消息、证书等通答平台模块。
5. 通过 AI 情景模拟、AI 评阅和专家数字人提升实操能力。
6. 通过管理端看板、风险分级和智能督学提升培训完成率。
7. 通过结业判定、证书发放和成长档案沉淀形成完整培训结果。

### 1.4 用户角色

| 角色 | 核心诉求 | 主要使用模块 |
|---|---|---|
| 学员 | 知道学什么、怎么学、差在哪、如何通过考证或岗位验证 | 入学、前测、学习计划、知识图谱、任务、情景模拟、模考、证书 |
| 学习服务管理员 | 管理学习服务空间、运营分组/班级、学员、进度、风险、结业和证书 | 空间管理、分组管理、看板、督学、结业审核 |
| 专家/教研人员 | 维护课程、题库、情景题、评分标准和专家知识库 | 资料库、题库、情景任务、专家数字人、知识图谱 |
| 平台运营人员 | 配置规则、标签、消息、问卷、智能体能力和运营策略 | 配置中心、标签中心、问卷、消息、智能体工具 |
| 系统管理员 | 管理租户、组织、权限、接口、审计和安全策略 | 组织权限、系统配置、审计日志、接口管理 |

### 1.5 核心业务闭环

AI 入学画像 → 前测评级 → 个性化学习计划 → 知识图谱学习 → 情景模拟实操 → 动态调优 → 模考/岗位验证 → 结业判定 → 证书与成长档案沉淀。

### 1.6 学习服务模式

本系统采用开放式学习模式和个性化学习服务，不采用一刀切的项目制学习模式。系统不要求所有学员在同一项目周期内按同一课程顺序、同一任务节奏完成学习，而是根据学员画像、能力基线、目标等级、岗位方向和可投入时间，动态生成个人学习路径。

在该模式下：

- 学习服务空间是长期开放的学习服务场域，承载方向、等级、资源、任务、专家和学习支持。
- 学员进入空间后获得个人学习计划和每日任务，不被统一项目进度锁死。
- 项目、班级、批次更多承担运营分组、权限控制、数据统计、督学管理和阶段活动组织，不决定每个学员的具体学习路径。
- 研习社学习广场承担跨空间、跨人群的开放学习入口，帮助学员发现公开课程、专家活动、案例讨论和优秀成果。

## 2. 总体产品架构

### 2.1 通答平台复用能力

系统建设不另起孤立平台，而是在通答平台现有模块基础上扩展在线学习服务师培训业务。

| 通答平台能力 | 在本系统中的用途 |
|---|---|
| 空间 | 承载开放学习服务空间、个性化学习现场、资料、讨论、任务和活动 |
| 研习社/学习广场 | 承载跨空间公开学习入口、专家内容、公开课程、活动、讨论、案例分享和优秀成果展示 |
| 资料库 | 承载国标、课程、题库、案例、知识卡片、专家授权资料 |
| 知识图谱 | 承载职业功能、工作内容、知识点、技能要求和资源绑定关系 |
| 能力模型 | 承载九维能力雷达、能力分层、报考等级建议和成长路径 |
| 课程工作台 | 辅助课程体系建设、课程资源组织和课程方案生成 |
| 任务模块 | 承载每日学习任务、补强任务、督学任务和作业任务 |
| 日历模块 | 承载学习计划、直播活动、模考时间、作业截止和答疑安排 |
| 问卷模块 | 承载入学问卷、学习反馈、督学回访、满意度调查 |
| 消息模块 | 承载学习提醒、督学通知、专家推荐和系统消息 |
| 证书模块 | 承载结业证明、学时证明、专项能力证明和证书核验 |
| 档案模块 | 承载学员成长记录、能力变化、证书、学习成果和训后画像 |
| 智能体 | 承载入学引导、答疑、规划、推荐、评阅、督学和跨模块调度 |
| 组织权限 | 承载租户、机构、班级、角色、数据范围和工具调用权限 |

### 2.2 智能体调度总原则

智能体不只是问答助手，而是通答平台的业务调度中枢。智能体应能根据用户意图、学习状态、学习服务规则和管理员指令，调用通答平台内的问卷、任务、日历、空间、研习社学习广场、资料库、消息、知识图谱、能力模型、证书、档案等模块完成业务动作。

典型示例：

- 学员首次进入学习服务空间时，智能体调度问卷模块发放入学问卷，并调度任务模块创建前测任务。
- 学员连续 5 天未学习时，智能体调度消息模块发送提醒，调度问卷模块采集原因，调度任务模块生成补学任务。
- 学员情景模拟低分时，智能体调度资料库推荐资料，调度专家数字人发起专项咨询入口，调度任务模块创建补练任务。
- 学员需要拓展学习时，智能体可从研习社学习广场推荐公开课程、专家直播、案例讨论和优秀成果。
- 管理员输入“找出连续 5 天未学习的学员并发起督学”，智能体自动查询风险名单、生成话术、发送消息、创建任务、安排回访问卷。

### 2.3 总体模块清单

1. 学习服务空间、运营分组与学习广场管理模块
2. 智能入学与学员画像模块
3. 前测与能力建模模块
4. 个性化学习计划、任务与日历模块
5. 知识图谱学习模块
6. 题库、练习与测评模块
7. 情景模拟与 AI 评阅模块
8. 专家数字人与智能体调度模块
9. 模拟考试与岗位验证模块
10. 结业判定、证书与成长档案模块
11. 管理端督学促学模块
12. 系统配置、规则与安全模块

## 3. 模块一：学习服务空间、运营分组与学习广场管理模块

### 3.1 模块目标

用于建设“在线学习服务师”开放学习服务空间，承载长期开放的学习资源、能力路径、个性化任务、专家服务和运营支持。空间不是一刀切的项目班级容器，而是学员持续进入、动态学习、按个人节奏成长的服务场域。项目、班级、批次作为运营分组存在，用于权限、统计、督学和阶段活动管理。同时将研习社作为学习广场，承载跨空间公开学习内容、专家活动、案例讨论和优秀成果展示。

### 3.2 主要页面

1. 学习服务空间列表
2. 新建/编辑学习服务空间
3. 学习服务空间详情
4. 运营分组/班级管理
5. 学习服务规则配置
6. 学习服务空间入口
7. 学习服务数据看板
8. 学习广场配置
9. 学习广场入口

### 3.3 核心功能

#### 3.3.1 学习服务空间创建

管理员可创建学习服务空间，字段包括：

| 字段 | 说明 |
|---|---|
| 空间名称 | 学习服务空间展示名称 |
| 空间编码 | 全局唯一，用于数据关联 |
| 服务对象 | 考证人群、在岗提升人群、转行入门人群 |
| 开放方式 | 长期开放、限期开放、邀请开放 |
| 支持赛道 | 考证赛道、成长赛道、混合赛道 |
| 支持等级 | 五级、四级、三级、二级、一级 |
| 关联知识图谱 | 指定本空间使用的国标知识图谱 |
| 关联能力模型 | 指定九维能力模型或岗位能力模型 |
| 关联课程包 | 指定必修课、选修课和公共课程 |
| 关联题库 | 指定前测、练习、模考、岗位验证题库 |
| 关联专家数字人 | 指定可服务本空间的专家数字人 |
| 是否启用 AI 入学 | 控制首次进入空间是否进入 AI 入学 |
| 是否启用前测 | 控制是否要求前测后再生成学习计划 |
| 是否启用每日计划 | 控制是否生成每日学习任务 |
| 是否启用模考 | 控制考证赛道是否开放模考 |
| 是否启用结业证书 | 控制达标后是否生成证书 |

#### 3.3.2 创建时机与创建责任

学习服务空间不是每个学员、每个班级或每个阶段性项目都新建一个，而是在某一类长期学习服务上线前创建。学员进入后生成的是个人画像、个人学习计划和个人任务，不是个人专属空间。

创建时机：

- 产品首次上线前，由平台方创建默认学习服务空间，例如“在线学习服务师数字专家学习空间”。
- 新增职业方向、目标等级、岗位方向或能力主题，且学习规则、知识图谱、课程包、题库或专家服务存在明显差异时，可新建独立学习服务空间。
- 某机构或租户需要私有化内容、独立权限、独立证书或独立运营规则时，可创建机构专属学习服务空间。
- 阶段性招生、培训批次、企业班级、考前冲刺营原则上不新建空间，而是在既有学习服务空间下创建运营分组、班级、批次或活动。

创建责任：

- 平台系统管理员：负责创建平台级默认学习服务空间、配置基础权限、开通工具能力。
- 平台运营/产品管理员：负责配置空间定位、服务对象、学习规则、知识图谱、课程包、题库、专家数字人和证书规则。
- 租户/机构管理员：在获得授权后，可创建或申请创建机构专属学习服务空间，也可在已有空间下创建运营分组。
- 班主任/辅导员：不创建学习服务空间，主要创建或维护运营分组、班级、督学任务和阶段活动。
- 智能体：可辅助生成空间配置草稿、规则建议和资源绑定建议，但创建空间、发布空间和开放学员访问必须由具备权限的管理员确认。

#### 3.3.3 空间卡片与个人多卡片规则

在产品界面上，空间以卡片形式展示。卡片是用户进入某个学习服务场景的入口，不等于把课程、题库、资料库完整复制一份。卡片背后可以是平台级学习服务空间、机构专属空间、个人成长空间或专项训练空间。

一个人可以拥有多张空间卡片，但每张卡片必须代表一个相对稳定的学习目标、职业方向或服务场景，不能因为每个任务、每次活动、每个资料都生成一张卡片。

主成长空间卡片的首次初始化规则：

- 触发时机：学员首次完成 AI 入学对话、入学问卷或调研采集，并满足最低画像字段后，系统自动初始化主成长空间卡片。
- 最低画像字段：学习目标、当前身份/岗位、基础水平、目标方向、每周可学习时间。缺少关键字段时，系统展示“待完善入学信息”，不生成正式主成长空间卡片。
- 初始化依据：调研结果用于初始化，前测结果用于校准。
- 初始化状态：调研完成但未前测时，卡片状态为“待前测校准”，相关学习路径、目标等级和推荐内容均标记为“初始建议”。
- 校准状态：前测完成后，系统将卡片状态更新为“已校准”，并刷新能力雷达、目标等级建议、学习计划、薄弱知识点和补强路径。
- 重复控制：同一学员在同一学习服务空间内只能有一张主成长空间卡片；再次调研只更新卡片画像版本，不重复创建主卡片。
- 人工调整：学员可修改学习目标、目标等级和每周可学习时间；修改后系统重新计算学习计划，并保留调整记录。
- 管理员视角：管理员可查看主成长空间卡片的初始化状态、前测校准状态和风险标签，但不得直接替学员修改个人学习目标，除非具备授权。

首次初始化内容：

| 初始化内容 | 来源 | 说明 |
|---|---|---|
| 学习目标 | 入学调研/AI 对话 | 考证、岗位提升、入门学习或混合目标 |
| 推荐赛道 | 学习目标 + 当前岗位 | 考证赛道、成长赛道或混合赛道 |
| 初始目标等级 | 学员选择 + 基础水平 | 前测后可被系统校准 |
| 学习周期 | 每周可学习时间 + 目标等级 | 生成初始周期，后续动态调整 |
| 今日任务 | 当前阶段 + 最小可执行动作 | 默认包含入学完成、前测、导学任务 |
| 推荐主题 | 画像标签 | 入门导学、等级备考、岗位训练、情景模拟等 |
| 推荐课程 | 画像标签 + 目标方向 | 从公共课程包中引用，不复制课程 |
| 推荐前测 | 目标等级 + 基础水平 | 自动创建前测任务 |
| 推荐专家 | 岗位方向 + 短板标签 | 可先基于调研推荐，前测后再优化 |
| 风险标签 | 时间、基础、目标清晰度 | 用于提醒、督学和任务量调整 |
| 首页组件 | 当前状态 | 待前测时突出前测入口；校准后突出能力雷达和今日任务 |

推荐卡片类型：

| 卡片类型 | 示例 | 创建方式 | 生命周期 | 说明 |
|---|---|---|---|---|
| 主成长空间卡片 | 我的在线学习服务师成长空间 | 学员首次完成入学后由系统自动创建 | 长期保留 | 承载个人主目标、画像、学习计划、能力雷达、证书进度 |
| 等级备考空间卡片 | 五级在线学习服务师备考空间 | 学员选择目标等级后创建，或由智能体建议后确认创建 | 达标后可归档或升级 | 专门服务某一等级考证目标 |
| 岗位提升空间卡片 | 学习运营岗位能力提升空间 | 学员选择岗位方向后创建 | 长期或阶段性保留 | 面向在岗能力提升 |
| 专项训练空间卡片 | 情景沟通专项训练空间 | AI 识别短板后建议创建，需学员确认 | 达标或到期后归档 | 用于短期补强，不长期占据首页 |
| 机构/班级空间卡片 | 某企业在线学习服务师提升班 | 管理员将学员加入运营分组后展示 | 批次结束后归档 | 承载机构组织、督学和阶段活动 |
| 学习广场卡片 | 在线学习服务师学习广场 | 平台默认展示 | 长期开放 | 承载公开课程、专家直播、案例分享和优秀成果 |

个人卡片内容包括：

- 我的学习目标
- 我的能力雷达图
- 我的今日任务
- 我的学习计划
- 我的知识图谱点亮进度
- 我的薄弱知识点
- 我的推荐课程
- 我的情景模拟任务
- 我的专家数字人推荐
- 我的错题本
- 我的模考记录
- 我的结业进度
- 我的证书和成长档案

卡片内容的个性化方式：

- 路径定制：不同学员的学习路径不同。
- 任务定制：每日任务按个人能力短板生成。
- 内容推荐定制：课程、题目、案例、专家按画像推荐。
- 节奏定制：学习计划按可投入时间动态调整。
- 报告定制：能力雷达、成长报告、补强清单按个人数据生成。
- 首页定制：每张个人卡片内展示与当前目标最相关的组件。

底层资产复用规则：

- 课程不复制，只做个性化引用。
- 题库不复制，只做个性化抽题。
- 知识图谱不复制，只记录个人节点状态。
- 资料库不复制，只做个人推荐、收藏和学习记录。
- 专家数字人不复制，只做个人匹配和咨询记录。

首页卡片分组建议：

- 我的主空间
- 我的备考/成长空间
- 我加入的机构/班级空间
- 专项训练空间
- 学习广场
- 已归档空间

#### 3.3.4 学习服务空间生成

学习服务空间创建后，系统自动生成空间首页和服务分区。空间内默认包含：

- 学习导航区
- 个性化任务区
- 资料区
- 讨论区
- 直播/活动区
- 问卷区
- 作业/成果区
- AI 数字专家入口
- 服务公告区
- 结业与证书区

#### 3.3.5 研习社学习广场

研习社可作为面向学员的学习广场，承载不局限于单个学习服务空间的公开学习内容和持续运营内容。

学习广场内容包括：

- 公开课程
- 专家直播
- 专家问答
- 学习专题
- 案例讨论
- 学员经验分享
- 优秀作业/成果展示
- 考证政策与备考资讯
- 岗位成长文章
- AI 推荐学习合集

学习广场与学习服务空间的关系：

- 学习服务空间承载某一职业方向、等级目标或能力主题下的长期学习服务。
- 学习服务空间内的学习计划由系统按个人画像和能力差距生成，不要求所有学员统一节奏。
- 学习广场承载“跨空间可发现、可参与、可持续运营的学习内容”。
- 学习广场内容可被管理员选入学习服务规则，成为必修、选修或公共环节。
- 学员在学习广场参与公开课程、讨论、问答和活动的行为，可按规则回流个人成长档案。
- 智能体可根据学员画像、薄弱能力和学习阶段，从学习广场推荐合适内容。

#### 3.3.6 运营分组与成员管理

支持按企业、学校、部门、班级、批次、目标等级导入或分组学员。运营分组用于权限、统计、督学、活动组织和证书批次管理，不强制决定学员学习路径。

功能包括：

- 批量导入学员
- 手动添加学员
- 设置学员所属机构/部门/班级
- 设置目标等级或服务方向
- 设置班主任/辅导员
- 设置专家
- 设置空间管理员
- 设置服务有效期
- 设置学员可见范围
- 设置分组专属通知
- 设置分组统计口径

#### 3.3.7 学习服务规则配置

管理员可配置：

- 入学流程规则
- 前测规则
- 学习计划生成规则
- 必修/选修任务规则
- 打卡规则
- 动态调优规则
- 模考规则
- 结业判定规则
- 证书发放规则
- 督学预警规则

### 3.4 业务规则

1. 一个学习服务空间必须绑定至少一个能力模型。
2. 一个学习服务空间可绑定一个或多个知识图谱。
3. 学员加入学习服务空间后，系统自动创建个人学习档案。
4. 若启用 AI 入学，学员首次进入空间时优先进入智能入学流程。
5. 若未启用 AI 入学，学员直接进入空间首页和今日任务页。
6. 空间数据权限应按租户、空间、运营分组、班级和角色隔离。
7. 学习服务空间可长期开放；阶段性项目或批次结束后，只归档该批次数据，不关闭学员个人持续学习入口。
8. 学习广场内容默认作为开放学习内容，不直接计入结业，除非被配置为某类学员的必修、选修或公共任务。
9. 学习广场行为可进入成长档案和积分/激励记录，但是否进入合格判定需由学习服务规则明确配置。
10. 班级、批次、考前营、企业专班默认作为运营分组管理；只有当服务内容、权限边界或规则体系需要长期独立运营时，才创建新的学习服务空间。
11. 学员可拥有多张空间卡片，但卡片必须对应明确学习目标、职业方向或服务场景。
12. 系统默认只自动创建一张主成长空间卡片；新增等级备考、岗位提升或专项训练卡片，应由学员主动选择或确认智能体建议后创建。
13. 专项训练卡片应设置完成条件或有效期，达标或过期后自动进入已归档空间。
14. 个人空间卡片只保存个性化计划、进度、记录和推荐，不复制底层课程、题库、资料库和知识图谱资产。
15. 主成长空间卡片必须基于入学调研结果初始化；调研未完成或关键字段缺失时，只展示公共学习空间入口和继续调研入口。
16. 前测完成前，主成长空间卡片内展示的目标等级、路径和推荐内容均为初始建议；前测完成后必须执行二次校准。
17. 二次校准不得覆盖历史调研数据，应生成新的画像版本、能力版本和学习计划版本，支持训前训后对比。

### 3.5 验收标准

- 管理员能创建学习服务空间，并配置关联课程、题库、知识图谱、能力模型和专家数字人。
- 班主任或辅导员只能创建运营分组、班级和阶段活动，不能直接创建学习服务空间。
- 智能体可生成空间配置建议，但正式创建和发布必须由管理员确认。
- 学员首次完成入学后，系统能生成默认主成长空间卡片。
- 主成长空间卡片能根据调研结果初始化目标、赛道、任务、推荐主题、推荐课程和风险标签。
- 前测完成后，主成长空间卡片能从“待前测校准”更新为“已校准”，并刷新能力雷达和学习计划。
- 同一学员在同一学习服务空间内重复调研不会生成重复主卡片，只会更新画像版本和计划版本。
- 学员新增明确目标后，可创建新的备考、岗位提升或专项训练卡片。
- 多张个人卡片之间应共享底层课程、题库、资料库和知识图谱资产，只区分个人计划、进度和记录。
- 学员进入学习服务空间后，能获得基于个人画像和能力差距生成的学习路径，而不是统一项目进度。
- 运营分组能支持权限、统计、督学和活动组织，但不强制覆盖学员个人学习计划。
- 学习服务规则能影响后续入学、前测、学习、结业流程。
- 学员达标后可进入结业判定和证书发放流程。
- 研习社学习广场可展示公开课程、专家活动、案例讨论和优秀成果，并可被学习服务空间引用。

## 4. 模块二：智能入学与学员画像模块

### 4.1 模块目标

通过智能体对话或问卷方式采集学员基础信息，生成结构化画像，为前测、学习计划、专家推荐和督学策略提供依据。

### 4.2 主要页面

1. AI 入学对话页
2. 入学问卷页
3. 学员画像页
4. 管理端画像字段配置页
5. 管理端入学话术配置页

### 4.3 核心功能

#### 4.3.1 AI 对话入学

学员首次进入学习服务空间后，由数字专家主动开启对话。

采集内容包括：

- 当前身份
- 当前岗位
- 从业年限
- 是否有在线学习服务经验
- 学习目标
- 报考目标等级
- 每周可学习时间
- 学习偏好
- 当前最大困惑
- 是否需要平台操作引导

#### 4.3.2 调度问卷模块

智能体可根据学习服务空间配置调用问卷模块，自动生成或发放入学问卷。

问卷类型包括：

- 基础信息问卷
- 学习目标问卷
- 岗位现状问卷
- 学习时间问卷
- 学习困难问卷

#### 4.3.3 画像生成

系统将对话和问卷结果转为结构化画像。

画像标签包括：

| 标签类别 | 示例 |
|---|---|
| 身份标签 | 考证学员、在岗人员、转行入门 |
| 目标标签 | 获取证书、提升岗位能力、补齐基础 |
| 基础标签 | 零基础、有经验、已学习过相关课程 |
| 岗位标签 | 班主任、运营、教务、培训管理、学习顾问 |
| 时间标签 | 每周 2 小时、每周 5 小时、碎片化学习 |
| 偏好标签 | 视频学习、图文学习、练习驱动、案例驱动 |
| 风险标签 | 时间不足、目标不清、基础薄弱、拖延风险 |
| 推荐标签 | 推荐初级路径、推荐专项补强、推荐专家咨询 |

#### 4.3.4 主成长空间卡片初始化

学员完成入学调研后，系统自动初始化“我的在线学习服务师成长空间”主卡片。

初始化流程：

1. 校验调研是否完成最低画像字段。
2. 生成或更新学员画像。
3. 判断该学员在当前学习服务空间内是否已有主成长空间卡片。
4. 若没有主卡片，则创建主成长空间卡片。
5. 若已有主卡片，则更新画像版本和首页推荐，不重复创建。
6. 创建前测任务，并将卡片状态标记为“待前测校准”。
7. 根据调研结果生成初始目标、推荐赛道、推荐主题、首批任务和专家推荐。
8. 前测完成后，将卡片状态更新为“已校准”，并刷新能力雷达、学习计划和补强路径。

初始化失败处理：

- 调研关键字段缺失：提示学员继续完成入学信息。
- 前测题库未配置：仍可创建主卡片，但前测任务标记为“待开放”。
- 推荐课程为空：展示学习广场和基础导学主题，提示管理员补充课程绑定。
- 专家数字人未配置：不展示专家推荐模块，但保留后续推荐位。

#### 4.3.5 平台入门指引

数字专家可回答：

- 如何开始学习
- 如何查看任务
- 如何参加前测
- 如何查看课程
- 如何提交作业
- 如何查看知识图谱
- 如何参加情景模拟
- 如何申请结业
- 如何查看证书
- 如何联系专家

### 4.4 业务规则

1. 对话入学与问卷入学可同时启用。
2. 若学员中途退出，系统保留已采集内容，下次继续。
3. 画像生成后允许学员修改基础信息，但能力类标签需通过测评更新。
4. 画像变化应记录版本，便于训前训后对比。
5. 入学画像生成后，系统自动创建前测任务。
6. 学员可查看本人画像摘要，管理员可按权限查看运营分组、班级或空间画像统计。
7. 入学调研完成后，系统应自动创建或更新主成长空间卡片；同一学习服务空间下不重复创建多张主卡片。
8. 调研结果只用于初始化个人成长空间，前测结果用于校准能力模型和正式学习计划。

### 4.5 验收标准

- 学员能在 3 分钟内完成入学采集。
- 系统能生成结构化画像。
- 系统能基于调研结果初始化主成长空间卡片。
- 调研未完成时，系统能提示继续完善信息，而不是生成空白卡片。
- 前测完成后，主成长空间卡片能自动校准学习计划和能力雷达。
- 管理员能查看画像字段和标签。
- 智能体能基于画像推荐前测和学习路径。
- 入学数据能用于后续学习计划、专家推荐和风险判断。

## 5. 模块三：前测与能力建模模块

### 5.1 模块目标

通过前测识别学员当前能力水平，输出九维能力雷达图、等级建议和成长差距，为学习计划生成提供依据。

### 5.2 主要页面

1. 前测说明页
2. 前测答题页
3. 前测结果页
4. 能力雷达图页
5. 管理端前测配置页
6. 管理端题库配置页

### 5.3 核心功能

#### 5.3.1 自适应组卷

系统根据画像自动选择试题：

- 考证人群：偏国标考点、理论知识、考试题型。
- 在岗提升人群：偏岗位场景、问题诊断、实操判断。
- 转行入门人群：偏基础概念、职业认知、入门能力。

#### 5.3.2 双模式判分

- 单选、多选、判断题：系统自动判分。
- 简答、情景案例题：AI 先评阅，必要时人工复核。

#### 5.3.3 能力模型写入

前测结果写入能力模型，生成：

- 九维能力雷达图
- 总体能力等级
- 报考等级建议
- 薄弱能力维度
- 薄弱知识点
- 推荐学习重点
- 推荐专家数字人

#### 5.3.4 前测报告

前测完成后，系统生成前测报告。报告内容包括：

- 总体得分
- 九维得分
- 强项能力
- 短板能力
- 推荐目标等级
- 建议学习周期
- 建议优先学习模块

### 5.4 业务规则

1. 前测题目必须绑定知识点、能力维度、等级和难度。
2. 前测完成后才能生成正式学习计划。
3. 学员可重新前测，但需记录多次测评历史。
4. 管理员可配置是否允许重测、重测次数和间隔时间。
5. 前测结果应同步更新学员画像、能力模型和知识图谱薄弱节点。
6. AI 评阅结果应保留评分依据和评语。

### 5.5 验收标准

- 系统可完成自动组卷、答题、判分。
- 前测结果能正确写入能力模型。
- 错题能关联到知识图谱节点。
- 学员能看到清晰的能力差距说明。
- 管理员能查看运营分组、班级和学习服务空间层面的前测分布。

## 6. 模块四：个性化学习计划、任务与日历模块

### 6.1 模块目标

基于画像和前测结果，自动生成个性化学习计划，并调度任务、日历和消息模块推进执行。

### 6.2 主要页面

1. 我的学习计划
2. 今日任务
3. 学习日历
4. 打卡记录
5. 补强任务页
6. 管理端计划规则配置页

### 6.3 核心功能

#### 6.3.1 学习计划生成

系统根据以下因素生成计划：

- 目标等级
- 当前能力水平
- 薄弱知识点
- 必修节点
- 每周可学习时间
- 服务周期或个人目标期限
- 合格判定要求
- 学员学习偏好

#### 6.3.2 每日任务生成

默认每日任务组合：

- 1 个知识点学习
- 5 道巩固题
- 1 个情景模拟或岗位实操片段

任务类型包括：

- 必修课
- 选修课
- 单元练习
- 情景模拟
- 总结反思
- 模拟考试
- 专家咨询
- 直播活动
- 作业提交
- 问答闯关
- 案例诊断

#### 6.3.3 调度任务模块

智能体可自动创建任务，包括：

- 今日学习任务
- 前测任务
- 补强任务
- 模考任务
- 作业任务
- 总结反思任务
- 专家咨询任务
- 督学回访任务

#### 6.3.4 调度日历模块

系统可将关键节点写入日历：

- 每日学习安排
- 直播课时间
- 作业截止时间
- 模考时间
- 结业申请时间
- 专家答疑时间
- 阶段复盘时间

#### 6.3.5 动态调优

规则示例：

| 触发条件 | 系统动作 |
|---|---|
| 连续 2 天未学习 | 发送温和提醒 |
| 连续 5 天未学习 | 智能体沟通原因并调整任务量 |
| 连续 7 天未学习 | 标记休眠或高风险，进入管理员督学名单 |
| 正确率持续高于 85% | 增加进阶内容 |
| 正确率低于 60% | 增加基础练习和专家推荐 |
| 情景模拟低分 | 创建补练任务并推荐专家数字人 |
| 必修节点滞后 | 调整学习计划优先补齐必修内容 |

### 6.4 业务规则

1. 学习计划必须覆盖结业所需必修内容。
2. 学习计划可动态调整，但结业必修要求不随计划减少。
3. 每日任务应可由学员查看、完成、延期或反馈困难。
4. 延期任务应自动进入后续计划重排。
5. 任务完成状态应同步知识图谱节点、能力模型和学习报告。

### 6.5 验收标准

- 前测完成后能自动生成学习计划。
- 今日任务能写入任务模块。
- 重要学习节点能写入日历。
- 学习进度变化后计划能动态调整。
- 学员和管理员都能查看计划完成情况。

## 7. 模块五：知识图谱学习模块

### 7.1 模块目标

将国标能力要求、课程、题库、情景模拟和学习状态统一映射到知识图谱，实现学习路径可视化和掌握状态可追踪。

### 7.2 主要页面

1. 知识图谱总览
2. 知识点详情
3. 知识点资源页
4. 薄弱路径推荐
5. 班级知识图谱热力图
6. 管理端图谱维护页

### 7.3 核心功能

#### 7.3.1 图谱结构

三级结构：

- 一级：九大职业功能
- 二级：工作内容/知识点
- 三级：技能要求/考点

#### 7.3.2 节点资源绑定

每个知识点可绑定：

- 课程
- 微课
- 资料
- 知识卡片
- 单元练习
- 情景题
- 专家数字人
- 直播回放
- 案例材料

#### 7.3.3 节点状态

节点状态包括：

- 未学
- 学习中
- 已掌握
- 实操过关

#### 7.3.4 智能体调度资料库

学员点击知识点后，智能体可从资料库检索：

- 相关课程
- 标准原文
- 案例材料
- 练习题
- 专家解释
- 常见误区
- 复习卡片

#### 7.3.5 薄弱路径推荐

### 7.4 业务规则

1. 必修节点全部达标后，过程达标才可能通过。

3. 情景模拟达标后，节点可变为“实操过关”。
4. 节点状态变化需同步能力模型和学习报告。
5. 节点资源绑定关系必须可追溯，避免课程、题目、资料孤立存在。

### 7.5 验收标准

- 学员能查看完整知识图谱。
- 知识点能跳转课程、题目、资料和情景任务。
- 学习完成后节点状态自动变化。
- 管理员能看到班级知识图谱热力图。
- 智能体能基于知识图谱推荐学习路径。

## 13. 模块十一：管理端督学促学模块

### 13.1 模块目标

### 13.2 主要页面

7. 督学效果报告

### 13.3 核心功能

#### 13.3.1 学习服务总览

展示：

- 参训人数
- 入学完成率
- 前测完成率
- 平均计划完成率
- 活跃率
- 模考通过率
- 预计结业率
- 证书发放数
- 平均学习时长
- 情景模拟完成率

#### 13.3.2 风险分级

默认分级：

| 风险等级 | 判定说明 |
|---|---|
| 绿色 | 正常学习 |
| 黄色 | 轻度滞后 |
| 橙色 | 明显滞后 |
| 红色 | 高风险或长期未学习 |

示例规则：

- 绿色：完成率不低于 80%，近 7 天有学习，正确率不低于 70%。
- 黄色：完成率 50%-80%，或近 3 天未学习。
- 橙色：完成率低于 50%，或连续 5 天未学习，或正确率低于 50%。
- 红色：连续 7 天未学习，或多次提醒无响应。

#### 13.3.3 智能督学

管理员可输入自然语言指令：

“找出连续 5 天未学习的学员，生成提醒，并安排一次回访问卷。”

智能体自动完成：

- 查询风险名单
- 生成督学话术
- 调用消息模块发送提醒
- 调用任务模块创建补学任务
- 调用问卷模块发起回访问卷
- 调用日历模块安排答疑活动
- 生成督学记录

#### 13.3.4 共性问题干预

当大量学员在同一知识点错误率过高时，系统提示管理员：

- 发起专项直播
- 推送补充资料
- 创建专项练习
- 推荐专家答疑
- 调整课程内容
- 更新知识卡片

### 13.4 业务规则

1. 风险分级规则应可配置。
2. 批量督学前应展示影响人数和发送内容预览。
3. 督学动作应记录干预时间、干预方式和后续效果。
4. 督学后 7 天应生成效果追踪结果。
5. 共性问题阈值默认可设为 40%，管理员可调整。

### 13.5 验收标准

- 管理员能查看学习服务空间总体运行状态。
- 系统能自动生成风险名单。
- 管理员能批量督学。
- 督学后能追踪 7 天内学习恢复情况。
- 智能体能完成跨模块督学动作。

| 系统管理员 | 管理租户、权限、接口和审计 |

### 14.4 安全要求

1. 专家资料必须有授权记录。
2. AI 回答需尽量基于知识库并可追溯来源。
3. 高风险操作必须二次确认。
4. 学员隐私数据按租户和角色隔离。
5. AI 工具调用必须完整留痕。
6. 学习数据、测评数据、证书数据不得跨租户访问。
7. 删除、停用、作废等操作应保留操作记录。

### 14.5 验收标准

- 管理员能维护关键规则。
- 不同角色权限边界清晰。
- 高风险操作有二次确认。
- 智能体工具调用有审计日志。
- 专家资料授权状态可追踪。

## 15. 关键验收场景

### 15.1 场景一：学员完整学习闭环

学员进入学习服务空间 → 完成 AI 入学 → 完成前测 → 获得个性化学习计划 → 每日完成任务 → 查看知识图谱点亮 → 完成情景模拟 → 参加模考 → 提交结业申请 → 获得证书和成长报告。

验收点：

- 全流程无断点。
- 学习数据能沉淀。
- 结业判定结果准确。
- 证书和成长报告可查看。

### 15.2 场景二：管理员智能督学

管理员查看看板 → 发现红色风险学员 → 让智能体生成督学方案 → 系统批量发送提醒 → 创建补学任务 → 发起回访问卷 → 7 天后生成督学效果报告。

验收点：

- 风险名单准确。
- 智能体能跨模块执行。
- 批量动作有确认和日志。
- 干预效果可追踪。

### 15.3 场景三：智能体调度平台模块

智能体根据学员状态自动调用：

- 问卷模块采集原因
- 任务模块创建补学任务
- 日历模块安排答疑
- 资料库推荐资料
- 消息模块发送提醒
- 知识图谱更新薄弱节点
- 证书模块生成结业证明

验收点：

- 每个模块调用成功。
- 调用失败有提示。
- 调用日志可查。
- 权限控制有效。

### 15.4 场景四：未达标补强

学员申请结业 → 系统发现模考未达标或必修节点未完成 → 拒绝结业 → AI 生成补强任务清单 → 学员完成后再次申请。

验收点：

- 未达标原因清晰。
- 补强任务与薄弱点匹配。
- 再次申请后能重新判定。
- 补强过程进入档案。

## 19. 非功能需求

### 19.1 性能要求

- 普通页面首屏加载应满足平台统一性能标准。
- 班级看板应支持至少千人级学员数据统计。
- 智能体调用工具时，应展示执行中状态。
- 大批量消息、任务、证书生成应异步执行。

### 19.2 可用性要求

- 学员端路径应尽量简洁，默认从“今日任务”进入学习。
- 管理端应支持按学习服务空间、运营分组、班级、机构、等级、风险状态筛选。
- AI 给出的计划、建议、评阅结果应可解释。
- 未达标原因应清楚展示，不只显示“未通过”。

### 19.3 安全与合规要求

- 用户数据按租户、学习服务空间、运营分组、班级、角色隔离。
- 专家素材必须具备授权记录。
- AI 输出不得编造政策、考试报名、证书效力等高风险信息。
- 重要业务结果应保留规则依据和审计日志。

### 19.4 可运营要求

- 规则可配置。
- 标签可维护。
- Prompt 可版本化。
- 题库和课程可审核。
- 专家数字人可启用、停用和更新知识库。

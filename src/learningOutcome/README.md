# 研修成果

入口为任务的“添加学习内容 → 研修成果”。添加时直接创建；打开后通过“成果配置”和“成果提交”页签分别配置和提交。配置页可设置材料类型、截止时间、评阅要求。批量创建学习任务的“要求提交研修成果”默认关闭。

## 当前存储和身份

本模块沿用应用原型的本地运行方式。成果和文件 Blob 保存在 IndexedDB `guoren-learning-outcomes-v1`，任务要求、进度沿用空间版本存储。只在同一浏览器和站点下持久化，不提供跨设备同步或服务端权限保障。

`sceneConfig.currentUser` 如含 `id`，使用该身份；否则生成本地匿名学习者身份。明确含 `canReviewOutcomes: true` 的当前身份可打开评阅列表。默认不提供匿名评阅权限。上线多用户服务时，必须将 store.js 的接口接入认证后端，服务端验证提交人、任务权限及评阅权限，并将文件迁移到对象存储。

## 行为

- `saveSubmission` 使用单个读写事务保存草稿或提交，冻结提交时材料（包括文件），相同内容重复提交不增加版本。
- 待评阅时不能再次正式提交；退回后修改内容可提交新版本。
- 草稿不计进度，自主提交或评阅通过计为完成；成果项影响父任务平均进度。
- AI伴学结果可关联到指定成果项，预览确认后保存草稿，并保留结果来源标识。
- 在线成果文档为可编辑的文本；已有文档关联保存当前可读取正文快照。Office文件可作为上传材料打开或下载，不在浏览器内提供Office编辑。
- 文件限制为文档、表格、幻灯片、图片、文本或zip。写入超出浏览器额度时提示失败，页面当前草稿不清空。

## 验证

运行 `npm run test:outcomes` 和 `npm run build`。存储测试覆盖文件保存、组合材料、身份隔离、版本快照、重复提交、退回重交、权限拒绝及逾期标记。

浏览器验收：直接添加成果项 → 打开成果配置页签 → 配置要求 → 切换成果提交页签 → 添加三类材料 → 保存草稿 → 刷新 → 提交 → 修改在线文档 → 提交新版本 → 查看历史。开启评阅需明确的当前评阅身份。浏览器工具禁用时不能将构建/存储测试视为页面交互验证。
